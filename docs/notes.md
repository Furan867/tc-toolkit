# notes 的用法

本文件只管一件事：**哪些笔记还能当依据**。它不是索引，不维护清单，也不复述内容。

## 对 2026-10-18 起的新文件

- 标题之后的正文第一行写状态，三选一：
  - `状态: 有效`
  - `状态: 部分作废（作废部分见 §X）`
  - `状态: 已作废（被 <篇名> 取代）`
- 标「已作废」的**不移动、不改名**（移动会让已有引用失效），只改这一行，并在正文写明被谁取代、为什么。
- 只写过程与证据（跑了什么、看到什么、结论怎么来的）；结论本身进 `facts/`。

## 对存量（2026-10-18 之前的笔记）

**未审计：不保证其中任何一篇与当前代码一致。** 引用前先按文件名日期判断先后，
再自行重跑该篇的命令或读源码确认；同一主题以更晚的为准。
作废关系不在此维护 —— 后续文件推翻前篇时，会在自己正文里写明。
