# M0 语料固化（180 份捕获 → 98 份唯一源码 + 离线重编译 manifest）

- 日期：2026-10-16
- 分支/目录：`simplexc/`（新增）；产物清单见下
- 目的：把 `work/hook/all/` 的捕获固化成可复现的语料 + 含 `entry` 的 manifest，给 M1+ 当输入

## 做法（四步）

1. **去重**：`work/hook/all/hook_src_*.si`（180 份）按源码**字节**去重 → 98 份唯一源码；
   `id` = 该源码的最小捕获编号（三位零填充）。字节去重与「按 md5 去重」等价（md5 只当键用，
   不进任何产物，所以工具里直接用字节做键，见 `recompile_corpus.py::unique_sources` 的说明）。
2. **离线重编译**：`try_compile_dll.load_dll(call_nimmain=False, quiet=True, prefer_real=True)`
   → `compile(out, src, flags=0)`，`Result = [out_len, out_ptr, entry, err_len, err_ptr]`。
   逐份 append + flush + fsync 一行 manifest，可续跑（按 `src_sha256` 跳过已有行）。
3. **交叉校验**：与**游戏内捕获的参考产物**逐字节比。⚠ 配对是
   `hook_src_NNN.si` ↔ **`hook_out_NNN.bin`**，不是同一文件名。
4. **两份非源码资产**：campaign 92 份 `test.si`（只拷不编译）+ stdlib 固定前缀
   （`compile_real.dll` 偏移 `0x119F48` 起 27711 B，含 55 处 CRLF；归一化后 27656 B，
   sha256 前缀 `b346c16ebccc6598`）。`corpus/ref/` 进 `.gitignore`。

## 结论（数字都是判据，可重跑）

| 项 | 值 |
|---|---|
| 捕获 → 唯一源码 | 180 → **98**；重复分布 1×91、2×3、3×2、4×1、73×1；重复最多 004(73 次)、001(4 次)、159 与 168(各 3 次) |
| 编译 | 98 份**全部成功**，无 abort；同一个进程内逐份串行，38.2 s（含 DLL 加载与落盘） |
| `entry` | 98 份全部非 0（53 个不同值，`0x212f` 出现 15 次，范围 `0x212f`..`0x14889`），且都 < `out_len` |
| 产物长度 | 与 `hook_out_<id>.bin` 全部相同（12019 B .. 631706 B） |
| `ref_match`（原始字节） | **0 yes / 98 no** —— 见下「为什么」 |
| `ref_match_rebased` | **98/98 yes**，差值恒为 `0x380000` |
| 同 boot 确定性 | 整轮重跑后 98/98 份 `out_sha256` 与上一轮相同；同进程内重复调 `compile()` 也逐字节相同 |

### 为什么 `ref_match` 全 no（这条是判据，不是缺陷）

参考产物里烘焙着**编译进程的 `compile_real.dll` 加载基址**（`movabs r64,imm64` 立即数）：

- 本次产物里的地址落在 **compile_real.dll 自己的镜像**里：偏移 `0x1310`/`0x1320`/`0x1350` 落在
  `.text`（像 call 目标），偏移 `0x131280` 落在 `.bss`（像数据槽位）。用
  `VirtualQuery` + `GetMappedFileNameW` 判定，98 对产物结论一致。
- 全语料差异共 **5553 个站点**，**全部**是 image 空间的 `movabs` 立即数（未分类 0 处），
  归到 `.bss` 4181 处 + `.text` 1372 处；差值恒为 `0x380000`，把差值减掉后 **98/98 逐字节相同**。
- 差值来源：参考产物基于 `0x7FF9A0DE0000`，本次基于 `0x7FF9A1160000`。该基址**按 boot 随机、
  同一宿主进程内跨进程恒定**（本机 `python.exe` 连开 3 个进程实测同一基址）→ **跨 boot 逐字节不可复现**。
- 转发层是**在宿主（游戏）进程内** `LoadLibraryA` 加载 `compile_real.dll` 的
  （`tools/compile_hook.c` 的 `ensure_real`），所以捕获里的地址在游戏进程里有效 —— 这条决定了
  离线产物不能直接拿去游戏里跑，除非基址归一化。

→ 所以 `ref_match` 保留原始字节比较（诚实 `no`），另用 `ref_match_rebased` + `rebased_delta`
表达「同一个模块镜像、只是基址不同」；`--check` 里这三条断言（未分类=0 / 差值恒定 / 归一化后逐字节相同）
任一不成立就报错退出。

## 踩到的坑

- `VirtualQuery` 对**未分配**区间也返回成功（`State = MEM_FREE`、`AllocationBase = 0`），
  不显式判就会把空闲区当成已映射区（`classify_abs_addrs.py::query_mapping` 注释里有）。
- `--check` 必须**不加载 DLL** 也能跑：归一化判据只依赖产物字节，不需要活进程映射。
- 编译前若发现源码 `{}` 不平衡就该停 —— 本轮 98 份都平衡，编译也全过。
