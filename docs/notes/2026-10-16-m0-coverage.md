## 判不准 / 可能是误报

1. `'…'`（27/98）语义未定：`Str` 的另一种写法，还是 `Cstring`/char 类别？语料里只在比较位置出现（`label == 'Program'`），没有赋给变量的用例 → 「当字符串」是假设，写进 `facts.md` 前要先做最小实验。
2. `字符串索引/切片` 98/98 只证明「Str 名字被下标」；`[a..b]` 切片**0 处**（唯一 `..` 在注释里）。
3. `指针算术` 只认本文件顶层声明的 Ptr 名字（`var x = Ptr …`、`raw_cast(<Ptr|Arr…`）→ 98/98 是下界不是计数；`sized int 转换` 只匹配带括号的 `U8 (x)`，不带括号的 `U8 text[i]` 未计入 → 真实使用面比 27472 行更宽。
4. `enum 成员作为值` = 「成员名出现在成员表以外」；134 个成员名与本文件 var/let/参数/def 名无重名（已查），未发现误报，但分不出「当值用」与「仅同名」。
5. `空函数体 {}`、`内嵌 def（闭包）` 是生成器的形态，不是语言规范里的构造名。
6. `大整数常量` 命中的多是硬编码地址（`Ptr 2416573349888`）；它们同时是宿主地址表（接口文档 §6）的输入。
