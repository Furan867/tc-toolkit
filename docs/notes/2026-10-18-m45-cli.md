# M4.5 接线：C++ CLI + 三条判据（2026-10-18）

## 产出

`simplexc/cli/simplexc_cli.cc`（新）：`.si` → `ModuleAst` → `lower::Program` → `assemble()` → blob，
不碰游戏、不经 Python。构建目标 `python simplexc/tools/build.py simplexc_cli` → `build/simplexc_cli.exe`。
`simplexc/compile_flags.txt`（新）给 clangd 用（之前只有 `shell/` 有一份，`cli/` 的 include 解析不了）。

`ModuleAst` 要由调用方填（`label`/`defs`/`top_vars`/`enums`/`structs`），所以 CLI 补了原型的
`_scan_decls`/`_scan_type`/`parse_decl_stmt` 三段：type 声明手写扫描（生成代码子集里只有
`type X Enum [a, b]` 与 `type X Struct { f: T }` 两种），顶层 `var`/`const` 切 token 交给
`Parser::parse_statement()`，**只解析可达 def**（`Frontend::live`；`rv32im.si:154` 那个多余 `)` 在不可达 def 里）。

## 判据

**① 逐 tick 等价（核心）**：
```
build/simplexc_cli.exe --src simplexc/corpus/rv32im/rv32im.si --out work/tmp/lower/cpp_rv32im.bin
→ blob 26340 B（机器码 26332）/ entry 0x63A0

host.py --seed-reset-data seq --ticks 10（参考 0x215B vs 我们的 0x63A0）
→ ref tick=10 段=6 / cpp tick=10 段=6 → 差异 0 条 PASS
```

**② 延迟门**（`corpus/src/177.si`，479225 B，最大语料）：
```
前端=38 ms  lowering=13 ms  LLVM(O2+代码生成)=212 ms  装配=1 ms  合计=266 ms
外部 wall（含进程启动 + 文件 IO）= 479 ms
```
门是 ≤4 s → **15 倍余量**。前端 + lowering 只占 51 ms。

**③ 依赖门**：`objdump -p build/compile_hook.dll | grep -i python` 为空
（导入表只有 `KERNEL32.dll` / `msvcrt.dll`）。

**第四条（更严的同源对照）**：C++ 与 Python 对**同一份** `rv32im.si` 生成的 IR **逐字节相同**
（md5 `869677f0891a7884bcf025fc6384937e`，1379416 B）→ lowering 是精确搬运。

## 重大发现：Python 原型的机器码一直按 -O0 生成

同一份 IR、同样 `default<O2>`、同样 triple/PIC/Small，两边 COFF 差 2.2 倍：

| | .text | COFF | blob |
|---|---|---|---|
| Python (`ir_build.py`) | 0xE1E9 (57833) | 59047 | 58612 |
| C++ (`lower.cc`) | 0x6393 (25491) | 26843 | 26340 |
| clang `-O2` 编同一份 IR | 0x6393 | 26933 | — |
| clang `-O0` 编**已优化**的 IR | 0xE1E9 | 59137 | — |

根因：`ir_build.py:213` 写 `self.CodeGenLevelDefault = 0`，而 LLVM 的枚举是
`LLVMCodeGenLevelNone=0, Less=1, **Default=2**, Aggressive=3` —— **0 是 None（-O0）**。
所以 Python 的 `LLVMRunPasses(default<O2>)` 只优化了 **IR**（1379416 → 337239 B 实测），
机器码生成级别仍是 -O0。C++ 走官方 `llvm-c/TargetMachine.h`，拿到正确值 2。

**含义**：M3/M4 的所有 Python 产物（58612 B、游戏内 24.83 MHz）都是 **-O0 代码生成**的成绩。
Python 原型是冻结 oracle（只读纪律），**不改它**；但这条要进 `facts.md` ——
否则「C++ 产物小一半」会被误读成「C++ 写得更好」。
