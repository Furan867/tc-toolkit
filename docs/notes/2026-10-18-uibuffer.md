# B′ 8 份：`ui_buffer` 两段渲染串味 = 参考**每个 def 只有一份帧**

实现者（`simplexc/lower/**` 唯一写者）。器材 `work/tmp/uibuf/`（探针、coverage 三份产物、pi-lens 输出都不入 git）。

## 一句话

参考里**同一个 def 的多次调用共用同一块结果缓冲**（非重入帧）：后一次调用连内容带头里的长度一起覆写前一次的，
所以 `` `…{f(a)}…{f(b)}…` `` 里**每一段都渲染出 `f(b)`**。我们每次调用各拿一块栈缓冲 → 少渲染了前面几段。
`lower.cc:template_expr` 里按被调名把前一段的值改成后一段的值即可（26 行 diff，无其它文件）。
我们侧的同形读出（`python work/tmp/uibuf/probe_mini.py`，最小片段 + 我们的产物跑宿主）：
A `[right]    [F][F][F][F][F][F][T][F]    [F][F][F][F][F][F][T][F][/right]`(71) ·
S `[[F][T][T]|[F][T][T]|[F][T][T]]`(31) · W `[[T]|[T]]`(9) —— 与参考逐字节相同。

## 区分实验（`python work/tmp/uibuf/probe_ui.py ref`，参考编译器 + 差分宿主）

设计要点：**一次编译**跑完所有分支（每次参考编译约 15 s）。片段 = `work/tmp/ul7x/base.si` + 探针 def，
探针调用插在 `reset_sim()` 之后（顶层非声明语句我们的产物会丢，所以放进标签块里）。

| --- | --- | --- | --- |

⇒ 任务给的两个假设都不对：不是「同一字符串字面量里两次插值调用串味」（Y 例在模板外也串），
也不是「滚动槽偏了一帧」（W 例长度与内容都精确等于最后一次调用，偏帧解释不了）。

## 修法

`template_expr`：所有插值段先求值（顺序与参考一致），然后把**同一被调名的 Str 段**里靠前的那些换成最后那一段的
`V`（同一个 SSA 指针，不会重复调用）。只对「按名字直接调用」的段生效；字面量、变量、不同名调用一律不动。

## 遗留风险

1. **只模拟了模板内**：Y 形（在模板外把一个 def 返回的 `Str` 存下来、再调一次同名 def 才用）我们仍然“对”、
   参考会串。语料 98 份没有这种形状，但**它不是不可能出现**的形状，遇到时按同一条机理扩。
2. 串味的键是**被调名**：同名但不同泛型实例的两次调用会被当成同一个 def（参考那边是两个帧）。
   语料里没触发；真遇到要把实例化名并进键。
3. T/U/V/Z 说明「不同 def 不串」，但这只在两边**帧不重叠**时成立；参考的帧布局若真按 def 顺序分配，
   更深的情形（一个 def 叫另一个 def 再由调用者读前一个的值）没测。
