# libs/

被所有层依赖的 Python 库。**只依赖标准库**，不依赖 `tools/`、`services/`、`native/` 或任何产品。

| 放什么 | 例子 |
|---|---|
| 环境发现 | `tc_common.py`：游戏目录、版本、工具链 |
| 进程与内存原语 | `winmem.py` |
| 终端输出 | `term.py` |
| 日志与契约 | `hook_log.py`：`work/hook/hook.log` 的唯一读写实现 + 事件表 |
| 路径解析 | `paths.py`：`work/` 下目录的唯一来源（只给路径，不给"两个候选选哪个"的语义） |

**不放**：任何命令行入口、任何"这次实验才用"的脚本、任何读游戏内存的业务逻辑（那在 `services/` 或产品里）。

新增一个模块前先问：它会不会 import 上面这些以外的东西？会，就说明它不属于这一层。
